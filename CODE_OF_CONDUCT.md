# Code of Conduct

## Our Commitment

The Prut project is committed to providing a welcoming, respectful, and constructive environment for everyone who participates.

We want Prut to be a place where people can learn, experiment, contribute, and share ideas without harassment or hostility.

## Expected Behaviour

Project participants are expected to:

* Be respectful and considerate.
* Communicate constructively.
* Welcome different viewpoints and experiences.
* Give useful and respectful feedback.
* Focus discussions on the project and its goals.
* Accept constructive criticism.
* Respect decisions made by project maintainers.

## Unacceptable Behaviour

The following behaviour is not acceptable:

* Harassment or discrimination.
* Personal attacks or insults.
* Threats or intimidation.
* Deliberate disruption of project discussions.
* Publishing someone's private information without permission.
* Sexual harassment or inappropriate sexual content.
* Trolling or repeated bad-faith behaviour.
* Any other behaviour that would reasonably make the project unsafe or hostile for others.

## Reporting Problems

If you experience or witness unacceptable behaviour, report it privately to the project maintainers through the contact method listed in the repository.

Reports will be handled as respectfully and confidentially as possible.

## Enforcement

Project maintainers may take appropriate action in response to unacceptable behaviour, including:

* Asking someone to stop the behaviour.
* Removing inappropriate content.
* Temporarily restricting participation.
* Permanently restricting participation in serious or repeated cases.

## Scope

This Code of Conduct applies to project spaces, including:

* GitHub issues.
* Pull requests.
* Discussions.
* Code reviews.
* Project-related communication.

## Attribution

This Code of Conduct is based on common open-source community standards and has been adapted for the Prut project.
